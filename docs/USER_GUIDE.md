# Uso

Entrar con la cuenta asignada y cambiar contraseña inicial. Jason administra biblioteca/Drive; su pareja ve, conversa y puede recibir el anfitrión. No hay registro público.

Jason añade archivo, enlace HTTPS compatible o selección Drive autorizada. El worker prepara archivos antes de publicarlos y conserva originales. “Preparar varias calidades” genera variantes reales sin superar la fuente. Publicar muestra la ficha a ambos; retirar impide nuevos accesos. No se incrustan páginas de plataformas.

En la ficha elegir ver solo o iniciar sala. Los progresos personales y compartido son separados. Ambos pulsan “Pulsa para activar la reproducción”. El anfitrión controla play/pausa/seek/velocidad; “Pasar el control” transfiere autoridad sin reiniciar. “Pedir el control” avisa; reclamar solo es válido tras ausencia del anfitrión.

“Esperarnos” pausa cuando falta preparación. “Continuar sin esperar” permite una continuación explícita. Recuperar buffer conserva una pausa voluntaria. Reconectar recupera primero estado oficial; las órdenes offline no se acumulan.

Volumen/mute/calidad/subtítulos/presentación son individuales. Ajustes solo muestra capacidades existentes. Subtítulos: tamaño, fondo y desfase −5 a +5 s. Fullscreen/PiP dependen del navegador. K/Espacio: play/pausa; J/L: ±10 s; flechas: ±5 s; M: mute; F: fullscreen; C: subtítulos. Los atajos no interceptan formularios.

“Usar este dispositivo” transfiere el lease de la cuenta y retira mando al dispositivo anterior. Cerrar vídeo guarda progreso y conserva chat. Cuenta permite cambiar nombre/contraseña y revocar sesiones. Jason puede generar reset de un uso; recuperación CLI guarda enlace en archivo privado sin imprimir token.

Todavía falta alojamiento HTTPS para acceso remoto y OAuth real para Drive. No existe una URL pública acreditada.
